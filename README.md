## Library Management System
A Frappe-based app for managing library operations like books, members, memberships, and transactions.

## Features
Manage Articles: Add and update books or articles.
Member Management: Track library members.
Memberships: Manage memberships and plans.
Transactions: Issue, return, and track fines.
Settings: Configure library rules and policies.
## DocTypes
Article: Catalog of books/articles.
Library Member: Details of library members.
Library Membership: Track memberships and plans.
Library Transaction: Handle book issuing, returning, and fines.
Library Setting: Configure operational rules.
## Installation
Clone the repository:
git clone https://github.com/yogitajibhakate/Library_Management_Frappe.git
Install the app:
bench install-app library_management

Start the server:
bench start
