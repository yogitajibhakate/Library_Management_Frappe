## Library Management System
A Frappe-based app for managing library operations like books, members, memberships, and transactions.

## Features
Manage Articles: Add and update books or articles.<br>
Member Management: Track library members.<br>
Memberships: Manage memberships and plans.<br>
Transactions: Issue, return, and track fines.<br>
Settings: Configure library rules and policies.<br>
## DocTypes
Article: Catalog of books/articles.<br>
Library Member: Details of library members.<br>
Library Membership: Track memberships and plans.<br>
Library Transaction: Handle book issuing, returning, and fines.<br>
Library Setting: Configure operational rules.<br>
## Installation
Clone the repository:
git clone https://github.com/yogitajibhakate/Library_Management_Frappe.git<br>
Install the app:
bench install-app library_management<br>
Start the server:
bench start
